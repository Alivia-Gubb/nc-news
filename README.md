# Northcoders News API
A robust back-end system using JavaScript, SQL, and Express. The project involved designing and implementing a RESTful API to handle CRUD (Create, Read, Update, Delete) operations. I utilised Express to create server-side logic and route management, ensuring efficient handling of client requests. SQL was used for database management, allowing for structured storage, retrieval, and manipulation of data. I also incorporated testing using Jest to ensure code reliability and functionality, writing comprehensive test cases to validate API endpoints and database interactions. Through this project, I demonstrated proficiency in building scalable and maintainable back-end solutions, focusing on data validation and error handling to ensure a secure and reliable application


This portfolio project was created as part of a Digital Skills Bootcamp in Software Engineering provided by [Northcoders](https://northcoders.com/)
